## Scaricare Slopperino

Apri la sezione **Releases** sulla destra e seleziona la versione piu recente.
Scarica **Slopperino_Setup_2.8.0.exe** e **SHA256-2.8.0.txt** dalla stessa release.

Slopperino richiede Windows 10/11, Zotero, Obsidian con CLI attiva e il plugin ZotLit. Le istruzioni dettagliate sono nelle note della release.

## Sicurezza

Il setup e attualmente **non firmato digitalmente**. Verifica il checksum SHA-256 e scansiona il file con il tuo antivirus. Non disabilitare antivirus, Chrome o SmartScreen per eseguire il software.

## Funzionamento

Il Bridge locale si avvia automaticamente in modo invisibile. La sincronizzazione Zotero/Obsidian puo essere avviata dal collegamento **Slopperino - Aggiorna note**. La diagnostica e facoltativa; il controllo aggiornamenti non installa nulla automaticamente.
